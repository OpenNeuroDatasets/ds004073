# Standard-space t-statistic derivatives

## Overview

This derivative dataset contains selected (see note below) first-level t-statistic maps from FSL FEAT analyses of the ds004073 dataset.

Note: data for the WC task for sub-OXF13 was missing so there are only 7 maps for this participant; all data for sub-BAN20 were excluded because the original EPI data were corrupted.  

A total of 399 NIfTI t-statistic maps are included in this derivative dataset. 50 participants, one (sub-OXF13) has 7 maps and the remaining 49 have 8 maps.

The maps have been transformed from functional space into MNI152 standard space using the linear functional-to-standard registration matrix generated by FSL FEAT:

`reg/example_func2standard.mat`

The corresponding nonlinear FEAT warp was **not** used for these derivatives.

The FEAT standard-space image:

`reg/standard.nii.gz`

was used as the reference image for the resampling.

## Contrasts included

The following contrasts were retained from the first-level FEAT analyses:

| Task | FEAT contrast | Contrast description |
| ---- | ------------: | -------------------- |
| PD   |             1 | PD-rest              |
| SC   |             1 | SC-rest              |
| SD   |             1 | SD-rest              |
| WC   |             1 | WC-rest              |
| SG   |             1 | SGgen-rest           |
| SG   |             2 | SGrep-rest           |
| WG   |             1 | WGgen-rest           |
| WG   |             2 | WGrep-rest           |

The number of available maps may vary between participants depending on the analyses completed for that participant.

## File naming

Files use BIDS-style entities to identify participant, task, spatial reference, and contrast. For example:

`sub-OXF01_task-PD_space-MNI152_desc-PDrest_tstat.nii.gz`

The components identify:

* `sub-OXF01`: participant
* `task-PD`: task
* `space-MNI152`: MNI152 standard space
* `desc-PDrest`: the contrast represented by the map
* `tstat`: t-statistic map

## Spatial transformation

For each selected FEAT contrast, the original t-statistic image was taken from the FEAT `stats` directory:

`stats/tstatN.nii.gz`

and transformed using the affine transformation:

`reg/example_func2standard.mat`

with the FEAT standard-space image:

`reg/standard.nii.gz`

as the reference.

Only the linear transformation was applied. The nonlinear files, including:

`reg/example_func2standard_warp.nii.gz`

were not used.

## Software

The first-level analyses were performed using FSL FEAT version 6.

## Interpretation

These files contain t-statistic values rather than z-statistic values. The contrast number corresponds to the contrast ordering in the FEAT `design.con` file for the relevant task.

The derivatives are intended to provide standard-space statistical maps corresponding to the selected first-level contrasts and to facilitate reuse and comparison of the analysis results.

## Data integrity

The derivative dataset currently contains 399 NIfTI files occupying approximately 443 MB locally.

The derivative NIfTI files are stored as regular files rather than symbolic links.
